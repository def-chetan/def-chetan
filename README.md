## 💼 Featured Projects

**🌾 [AAVA — AI Agricultural Voice Assistant](https://github.com/def-chetan/AAVA-AI-Agricultural-Vioce-Assistant)**
Voice-first assistant giving farmers live crop prices, weather & next-day price forecasts by phone — cut govt data latency from 10s to **<0.4s** using Gemini + linear regression. `Python` `Gemini` `NLP`

<p align="center">✦ ✦ ✦</p>

**✍️ [Handwritten Document Digitization](https://github.com/def-chetan/Handwritten-Document-Conversion)**
Converts handwritten/printed docs into structured Word files — **0.141 CER**, YOLOv8 layout detection (0.751 mAP@50), hybrid Gemini + TrOCR extraction. `YOLOv8` `OpenCV` `python-docx`

<p align="center">✦ ✦ ✦</p>

**📄 [PDF → Markdown Document AI Pipeline](https://github.com/def-chetan/Conversion-of-pdf-to-markdown)**
Two-phase OCR + cleaning pipeline for healthcare data dictionaries — **7–33% token reduction, 0% data loss**, recursive batching to dodge GPU OOM. `PyTorch` `HuggingFace` `CUDA`

<p align="center">✦ ✦ ✦</p>

**📍 [Location-Based Attendance System](https://github.com/def-chetan/Location-based-attendance)**
Facial-auth + geo-verified attendance platform (OpenCV + DeepFace/ArcFace) with role-based check-ins, presented live to the CTO. `FastAPI` `React` `Firebase`
