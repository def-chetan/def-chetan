## 💼 Featured Projects

### 🌾 AAVA — AI Agricultural Voice Assistant
A voice-first assistant that lets farmers with basic feature phones get live crop prices, weather, and next-day price forecasts by speaking naturally in Hindi, Marathi, or English — built during a Software Engineering internship at Siddharth Infosys.
- Used **Google Gemini** to parse noisy regional speech and extract crop, location, and intent
- Optimized government Agmarknet data fetches from 10+ seconds down to **under 0.4 seconds**
- Built a **linear regression** model to forecast whether prices will rise, fall, or hold steady
- Designed reliable fallback systems so the assistant keeps working even when govt servers lag

### ✍️ Handwritten Document Digitization
An end-to-end pipeline that converts handwritten and printed documents into structured, editable Word files while preserving the original layout.
- Achieved a best **Character Error Rate (CER) of 0.141** on handwriting recognition
- Trained a 4-class **YOLOv8** detector (0.751 mAP@50) to isolate text, tables, figures, and page noise
- Built a hybrid VLM pipeline (**Gemini 2.5 Flash + TrOCR fallback**) with a 2D layout engine to rebuild original formatting

### 📄 PDF → Markdown Document AI Pipeline
A two-phase document AI pipeline, built during an AI/ML R&D internship at Amoeba Labs, that converts dense US healthcare data dictionaries into clean, structured Markdown.
- Combined deep-learning OCR with statistical cleaning layers for a **7–33% token reduction** with **0% data loss**
- Designed recursive batching in **PyTorch** to dodge GPU OOM crashes during multi-page inference on T4 GPUs
- Used fuzzy string matching (Levenshtein) + clustering to strip repeating headers/footers and cut LLM context drift

![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=flat-square&logo=pytorch&logoColor=white) ![HuggingFace](https://img.shields.io/badge/HuggingFace-FFD21E?style=flat-square&logo=huggingface&logoColor=black) ![CUDA](https://img.shields.io/badge/CUDA-76B900?style=flat-square&logo=nvidia&logoColor=white)

[![GitHub](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/def-chetan/Conversion-of-pdf-to-markdown)

### 📍 Location-Based Attendance System
A full-stack facial-authentication and geo-verified attendance platform, built during a Software Development internship at Nepal Telecom and presented live to the CTO.
- Built a 1:1 facial auth engine (**OpenCV + DeepFace/ArcFace**) matching live captures against ID photos
- Architected a **FastAPI + React.js** PoC streaming Base64 face crops with real-time confidence scores
- Added role-based (Admin/Supervisor/Employee) check-ins with geolocation verification + bulk Excel registration
